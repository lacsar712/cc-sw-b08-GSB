# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

已结案任务可在「冻结台」签发为只读导出包：签发那一刻的灯种、标称、实测、结论、理由被冻进包内。之后改测重判只刷新总览现行行，包内字段保持签发版。巡检员可翻阅导出包，不能签发。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3195 |
| 接口 | http://localhost:8195 |
| PostgreSQL | localhost:54395 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| calibrator | calib123456 | 可提交校准、改测重判、签发导出包 |
| inspector | insp123456 | 只看（可翻阅导出包，不可签发） |

## 启动

```bash
cd projects/16-spectrum-wavelength-desk
docker compose up --build
```

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. 菜单进「冻结台」：左侧「待签发」列出两笔已结案，右侧「已签发」初始为空。
5. calibrator 对两笔已结案点「签发」，右侧出现两个导出包；点开任一包，包内字段为签发那一刻的灯种/标称/实测/结论/理由。
6. 进某任务详情「改测重判」修改实测，总览该行刷出新结论；再回冻结台打开对应导出包，包内仍是签发那一刻的数字。
7. inspector 登录可进冻结台翻阅导出包，但看不到「签发」按钮；直接调 `POST /api/packages` 返回 403。
